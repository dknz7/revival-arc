Welcome to Vivarc

Arc's way of browsing, inside Vivaldi. A sidebar for your tabs, a command bar for everything else.

The sidebar

Favorites

The tiles at the top. Drag a tab onto the sidebar, or right-click a tab and choose Add to Favorites.

Pinned

Your folders and links, always one click away. Drag to reorder, drop onto a folder to file things. Navigate inside a pinned tab and it stays on its pin, shown as / and the page title; hover it to go back to the pinned page or separate the current page into its own tab.

Open tabs

Below the divider. They stay until you close them, or hover the divider and press Clear.

Spaces

The space selector at the bottom of the sidebar is always available: each is a space with its own tabs and pinned links (favorites are shared). Click one, or press Cmd + Option + Left / Right for the previous/next. Create one with Ctrl + Cmd + N (or click +). Spaces only group tabs: they share the profile's logins. A space lives in one window; see Spaces and windows below.

Profiles

The round avatars at the bottom of the sidebar are your Vivaldi profiles: separate logins, one window each. Click one to switch, press Ctrl + Cmd + 1..9, or use Ctrl + Cmd + Left / Right for the previous/next one. The + adds a new profile.

Your look

Hover the space name and click the palette to pick a color, intensity and grain for each profile.

Hide the sidebar

Press Cmd + S to hide the sidebar in the window you are in, and again to bring it back. Other windows keep theirs. A hidden sidebar stays hidden until you press the key again; meanwhile Cmd + L edits the address in the command bar. In the Dia layout there is also a button for it in the top row. After the first start on a new version, restart Vivaldi once: it reads its keys at launch.

Mute a tab

Right-click a tab and pick Mute Tab (or Unmute Tab). A tab playing sound shows a small speaker: click it to mute. A muted tab shows a crossed-out speaker in place of its icon: click it to unmute.

Drag tabs between windows

Drag a tab out past the edge of the window and it opens in a new window, as a plain tab of that window's default space. A toast in the new window offers Undo for 5 seconds. Drag a tab into another window's sidebar and it lands there, in the space that window shows. Pins, favorites, folders and a window's only tab stay put.

Spaces and windows

Click a space tile

It goes to where the space lives. If the space is in another window, that window comes forward showing it. Nothing is pulled out of the other window.

Bring it here, or send it away

Hold Shift and click a tile to bring that space into this window. Hold Cmd + Shift and click to send it to a new window of its own.

The dot

A dot on a space tile means the space lives in another window. The default space belongs to each window, so it has no dot and cannot be moved.

New tabs, favorites and pins

New tabs, links included, open in the space on screen. So do favorites and pins: if the tab you click is in another space or window, it is brought here instead of opening a second one.

Move to a space

Right-click a tab and pick Move to a space. Your window stays where it is. If another window shows that space, the tab goes there. If another window has the space tucked away, Vivarc says so and moves nothing: show the space in its window first.

Kept in step

If a window ends up on a space that was deleted, or a space is split across windows (after a window closes, say), Vivarc puts it right by itself. Clicking a split space gathers it.

Delete a space

Right-click a tile and pick Delete Space…. The question counts the space's tabs in every window, and warns you when a window would close with them.

The full rules are in docs/vivarc-rules.md in the Vivarc repository.

The New Tab menu

Open it

Hover + New Tab and click the chevron at its right. The rest of the row still opens the command bar. The menu has Search Tabs…, Start Page, Open Tabs (every window, by space), Recently Closed, Recently Closed Windows and Recently Cleaned.

Start Page

Opens Vivaldi's own start page, with your speed dials, in a new tab. Cmd + T still opens the command bar.

Clean Up Tabs

Closes the tabs in the space on screen that you have not used for 7 days, then offers Undo in a toast. Pinned tabs, favorites, the tab on screen, tabs playing sound, private tabs and the tabs of a visible split view are never cleaned. Cleaned tabs wait in Recently Cleaned for 30 days.

Clean Up Daily

A tick in the same menu (off by default; it is also in Vivarc Settings). Once a day it does the same for every space in every window, quietly.

Mute All Tabs

Mutes every tab in the window, and turns into Unmute All Tabs once they are.

Close All Tabs

Closes the same tabs the Clear button does, after asking first.

The Dia layout

A slim top row

Switch it on in Vivarc Settings: type settings in Cmd + T and look for Dia layout. Vivaldi's menu, a sidebar button, Back, Forward and Reload, the page as site / title, a Shield, Copy link, Translate and the window buttons sit in one row over the page.

Shield, Copy link, Translate

The Shield opens Vivaldi's site info under it: the connection, cookies, site settings, JavaScript and the Ad and Tracker Blocker level for the site. Copy link copies the address. Translate shows on pages not in English and translates the page into English; click it again for the original.

Narrow windows

When the window gets small, the row's other items give way and the window buttons stay. On a Mac the row starts after the traffic lights.

Per profile

Settings are saved for each profile. A profile that has not switched Dia on shows the Arc layout, which can look like Vivarc is missing: check Dia layout in that profile's settings.

Good to know

Site requests

When a site asks to send notifications, know your location or use your camera or microphone, the question shows as a card at the top right of the page, with the site's own options. Click one to answer. Close the card and a small Site request pending pill keeps it one click away. The address bar stays collapsed.

The right-hand panel

Pause the pointer at the right edge of the window and Vivaldi's panel slides in, also on a monitor whose right edge meets another screen.

Rearranging icons on a Mac

When you Cmd+drag toolbar or extension icons, let go of ⌘ before the mouse button. Vivaldi drops nothing if ⌘ is still held.

The address field

Switching tabs no longer pops the hidden address field open. Cmd + L edits the address when you want it.

Keyboard shortcuts

Cmd + TOpen the command bar
Cmd + LEdit the current page's address
Cmd + SHide this window's sidebar, or show it again. Other windows keep theirs.

Cmd + Shift + CCopy the current page's URL

The command bar

Jump to anything

Type to find open tabs, bookmarks and history, or paste a URL. Anything else is a web search.

Settings

Switch Vivarc features on or off: type settings in Cmd + T, or right-click the sidebar and pick Vivarc Settings…. They are saved for the profile.

Quick actions

Type history, downloads, pin, split, theme… and run the action that appears.

Search shortcuts

Type a short keyword, then press Tab to search that site directly. The keywords below work out of the box.

Search shortcuts

yt YouTube g Google d DuckDuckGo b Bing gm Gmail gd Drive gc Calendar m Maps gh GitHub so Stack Overflow npm npm mdn MDN w Wikipedia r Reddit x X li LinkedIn az Amazon tr Translate

Your own Vivaldi search engine nicknames work too, and win over these when they clash.

Coming from Chrome or another browser

Import your data

In the menu bar choose File > Import Bookmarks and Settings…, pick Chrome (or Safari, Firefox, Edge…) and tick what to bring: bookmarks, history, saved passwords.

Keep your extensions

Vivaldi is built on Chromium, so most Chrome extensions install straight from the Chrome Web Store.

Put your sites in the sidebar

Imported bookmarks stay in Vivaldi's bookmarks. Open a site, press Cmd + T, type pin or favorites and run the action to pin it.

Coming from Arc? Run ./vivarc.py import-arc in Terminal to bring your spaces, pins and site icons. The README explains the steps.
